# LOINC 節錄表補碼（545 筆）

更新日期：2026-11-10

## 為什麼要補

本機驗證器沒有完整 LOINC，`Observation.code`（required 綁定 `http://hl7.org/fhir/ValueSet/observation-codes`）只能靠自製節錄表判斷。
節錄表原本只取自健保署「附件11_全國醫事檢驗LOINC編碼對照表」（5,046 碼），但 PAS IG 的 `ConceptMap-nhi-loinc.json` 另外對照到 545 個附件11 沒有的 LOINC 碼
（例：健保碼 `09121C` 睪丸酯醇免疫分析 → `49041-7`）。照 IG 填這些碼會被誤擋：

```
Code '49041-7' from system 'http://loinc.org' does not exist in the value set 'LOINC Codes'
(http://hl7.org/fhir/ValueSet/observation-codes), but the binding is of strength 'required'
```

這 545 碼不是 PAS IG 1.3.0 新增的，1.1.0～1.3.0 的 ConceptMap 都一樣。

## 要改的檔案

位於部署機 `fumeScript\ig\` 底下：

| 用途 | 檔案 |
|---|---|
| PAS | `pas\package\CodeSystem-loinc-nhi-lab.json` |
| CI | `ci\package\CodeSystem-loinc-ci-validation-fragment.json` |

## 手動新增步驟

1. 先備份上面兩個檔案。
2. 打開檔案，找到 `"concept": [` 陣列的最後一筆，在它的 `}` 後面加逗號 `,`。
3. 把下方 JSON 區塊**方括號裡面**的 545 筆貼上去（最後一筆後面不要有逗號）。
4. 把檔案上方 `"count"` 改成 `5591`（原 5046 + 545）。
5. 以 UTF-8 存檔，重啟 TMHTFhirApi（啟動時會預載碼表，約 2 分鐘）。

注意：

- 新增的碼**沒有 `display`**（IG 的 ConceptMap 沒有提供 LOINC 正式名稱）。請勿自行填 `display`，填錯會變成「display 不符」錯誤。
- `designation` 是對應的健保項目中文名稱，僅供人看，不影響驗證；CI 那份要貼也可以，或只保留 `code`。
- 若部署機的檔案已經是 5,591 筆（或已含 `49041-7`），代表已補過，不要重複貼。

## 驗證方式

送一筆 `code` 為 `49041-7` 的 PAS 檢驗 Observation 到 `/validate/PAS/Observation-laboratory-result-twpas`，回應不應再出現 `Code '49041-7' ... does not exist in the value set`；
改用不存在的碼（如 `99999-9`）仍應報錯，表示代碼檢核仍正常運作。
